# 🧠 Brain Tumor Detection Using Deep Learning

An end-to-end deep learning application that classifies brain MRI images into four categories:

- Glioma Tumor
- Meningioma Tumor
- Pituitary Tumor
- No Tumor

The project uses TensorFlow and MobileNetV2 for transfer learning and is deployed as an interactive Streamlit web application.

## ✨ Features

- Upload brain MRI images (`.jpg`, `.jpeg`, `.png`)
- Classify images into four tumor categories
- Display prediction confidence score
- Real-time predictions through a web interface
- Trained deep learning model using transfer learning
- Confusion matrix and classification report for evaluation
