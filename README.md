# Brain Tumor Detection Using Deep Learning

A deep learning web application that classifies brain MRI images into:
- Glioma
- Meningioma
- Pituitary
- No Tumor

## Tech Stack
- Python
- TensorFlow / Keras
- MobileNetV2
- Streamlit
- Scikit-learn

## Model Performance
- Test Accuracy: 87%

## Features
- MRI image upload
- Tumor classification
- Confidence score
- Interactive web interface
